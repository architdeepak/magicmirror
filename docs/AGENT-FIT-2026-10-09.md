## Progress bug discovered by screenshot

The earlier successful task screenshot retained “Checking your mirror…” after completion. The packaged baseline `f03a7696553040122a810bc9b34d33cc0e640b22deec3f76ddbe92969801228c` fails the added progress-hidden assertion. Main-process completion sends a run-retirement event before renderer final cleanup, clearing its run ID so the final cleanup no longer owned the banner.

The retirement handler now hides progress when retiring its current run. Unit checks preserve a newer run on a stale event, ignore empty retirement events and support explicit retirement of all runs. The final real task passes the progress-hidden assertion and leaves ready controls.
